# KMUTNB Open House 2027 - Student Activity Report

รายงานผลการปฏิบัติหน้าที่และเข้าร่วมกิจกรรมเปิดบ้านวิชาการ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ (KMUTNB Open House 2027) ภายใต้แนวคิด **AI Plus EDUCATION** โดยภาควิชาคอมพิวเตอร์ศึกษา (Department of Computer Education) คณะครุศาสตร์อุตสาหกรรม

## 📂 โครงสร้างเว็บไซต์
- **`index.html` / `report.html`**: หน้ารายงานฉบับทางการสำหรับส่งอาจารย์ (สะอาด เรียบร้อย ไม่มีปุ่มแก้ไข และรองรับการพิมพ์ / บันทึกเป็น PDF)
- **`edit.html`**: หน้าสำหรับนักศึกษาจัดการและแก้ไขข้อมูล อัปโหลดรูปภาพ และบันทึกหน้าที่ประจำวัน
- **`style.css`**: ดีไซน์ Responsive สไตล์ Modern Glassmorphism รองรับทั้งมือถือและคอมพิวเตอร์
- **`script.js`**: ระบบบันทึกข้อมูลอัตโนมัติ (LocalStorage) และการบีบอัดรูปภาพ
